# BINI Website Concept

This project is a fan-made concept website dedicated to BINI. It serves as a portfolio piece to demonstrate modern web development practices, UI/UX design, and content management integration.

---

## Technical Stack

This project implements a headless architecture to ensure high performance and content flexibility.

| Layer | Technology |
| :--- | :--- |
| **Framework** | Next.js (App Router) |
| **CMS** | Sanity.io |
| **Styling** | Tailwind CSS |
| **Deployment** | Vercel |

---

## Development Highlights

* **Headless Integration:** Content is decoupled from the frontend, allowing for seamless updates via the Sanity Studio interface.
* **Optimized Performance:** Utilizes Next.js Image optimization and static site generation where applicable.
* **Component-Driven UI:** Modular architecture focused on clean, maintainable, and scalable design patterns.
